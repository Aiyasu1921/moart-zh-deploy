## 上游

- 名称/URL：**MoArt** — https://moaang.github.io/moart/
- 基线版本：**ver1248**（本仓库 `main` 分支 = 上游 ver1248 汉化 + 一处绑定修复：清除烘焙的
  `data-*-bound/guard` 标记，恢复画布绘画与缩放）。
- 版权：上游版权归 Moaang，详见 `index.html` 版本信息对话框。

## 本项目新增功能（相对上游 ver1248）

- 更名 **MoArt-aiyasu**、版本号重置（当前发布 **ver1.1**）。
- **透视步进尺**（分镜·视频编辑）：透视线 → 灭点 → 垂心 / 90° 视场圆 → 角色校准 → 物距 →
  方向射线步进（纵深 / 斜向 / 中途改向）→ 撤销栈。
- **原画（genga）模式支持**：透视尺覆盖层随预览缩放 / 旋转 / 翻转。
- **保存/加载**：`perspGuide` 随项目 JSON / ZIP 持久化；旧文件安全回退。
- 部署：GitHub Pages 从 `ver1.0` 分支（内置 "Deploy from a branch"）部署；自定义
  `pages.yml` 仅手动触发（曾因与内置部署抢环境导致 deploy 失败，已修复）。

## 与原工具有意不同的行为

- **FOV/焦距以摄像机框为基准**（conte 480×270；genga 取项目 camera），不随摄像机运动变化。
- **步进矩形尺寸用精确针孔投影 `f·h/Z`**（保证头顶/脚底各自共线、同汇于视平线）；
  上游原型（PerspCal_v0.0.2.py）用 `atan` 近似。
- **默认步进方向 = 画布垂直向下**（走向镜头）；方向线为射线、一端固定角色脚底中点、只向前延伸、
  方向点单手柄；中途改向从“最近方框的下一个”起。
- **“撤销方向线”按操作快照逐条退回**（含同 from 替换），撤销栈不落盘。
- 工具面板在 genga 模式下同样可用（上游无透视尺功能，属全新能力）。
